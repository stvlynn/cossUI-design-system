Small status / metadata pill — used for the "Upcoming", "New" and count markers across coss.com.

```jsx
<Badge variant="info">Upcoming</Badge>
<Badge variant="success" size="sm">Live</Badge>
<Badge variant="outline">v1.18.6</Badge>
```

Tinted variants (`info`, `success`, `warning`, `error`) use an 8% fill with a colored label. `default` is solid near-black; `secondary`/`outline` are neutral.
