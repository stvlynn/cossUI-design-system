Primary action control — near-black filled by default; use it for the single most important action in a view.

```jsx
<Button variant="default" size="default">Get started</Button>
<Button variant="outline">Browse particles</Button>
<Button variant="ghost" size="icon"><SearchIcon /></Button>
```

Variants: `default` (primary), `secondary`, `outline`, `destructive`, `destructive-outline`, `ghost`, `link`.
Sizes: `xs · sm · default · lg · xl` plus square `icon · icon-sm · icon-lg`. Icons auto-size to 1rem and render at 80% opacity.
